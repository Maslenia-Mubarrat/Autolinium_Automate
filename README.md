# Autolinium

Autolinium is a full-stack internal office and KPI management system built to streamline employee operations, performance tracking, and administrative workflows in a corporate environment.

## Project Overview
The platform is designed to centralize day-to-day office management into a single application. It helps organizations monitor attendance, track employee productivity, manage leave requests, keep track of internal and client meetings, and compute performance-based KPI metrics.

## Core Functionalities
- Attendance tracking with check-in/check-out workflows
- Employee presence and punctuality analysis
- Leave and absence tracking
- Internal and client meeting compliance monitoring
- Task management and progress updates
- Weekly reporting and employee review workflows
- KPI-based performance scoring and incentive calculation

## Tech Stack

| Layer | Technology | Purpose |
| --- | --- | --- |
| Frontend | Next.js, React, Tailwind CSS | Admin dashboard and responsive employee-facing web interface |
| Backend | Node.js, Express.js, TypeScript | REST API, business logic, and server-side processing |
| Database | PostgreSQL | Relational data storage for users, attendance, meetings, tasks, reports, and KPI records |
| ORM | Prisma | Database modeling, migrations, and type-safe queries |
| Authentication | JWT + Cookies | Secure login and session management |
| Deployment | Vercel + Render / PostgreSQL hosting | Frontend and backend deployment with cloud database support |
| Architecture | Full-stack web application with admin and employee workflows | Centralized internal office operations and KPI management |
