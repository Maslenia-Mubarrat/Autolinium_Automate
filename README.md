# Autolinium

Autolinium is a full-stack internal office and KPI management system built to streamline employee operations, performance tracking, and administrative workflows in a corporate environment.

## Project Overview
The platform is designed to centralize day-to-day office management into a single application. It helps organizations monitor attendance, track employee productivity, manage leave requests, keep tabs on meetings and task progress, and evaluate performance using structured KPI metrics.

## Core Functionalities
- Attendance tracking with check-in/check-out workflows
- Employee presence and punctuality analysis
- Leave and absence tracking
- Internal and client meeting compliance monitoring
- Task management and progress updates
- Weekly reporting and employee review workflows
- KPI-based performance scoring and incentive calculation

## Architecture & Tech Stack

| Layer | Stack | Role |
| --- | --- | --- |
| Client | Next.js, React, Tailwind CSS | Admin panel and responsive employee UI |
| API | Node.js, Express.js, TypeScript | Handles business logic and exposes REST endpoints |
| Data Layer | PostgreSQL, Prisma | Stores and manages all application data securely |
| Security | JWT, Cookies, CORS | Handles authentication and protected API access |
| Hosting | Vercel, Render, PostgreSQL Cloud | Deploys frontend, backend, and database services |
| System Design | Full-stack SaaS-style internal platform | Manages attendance, KPI scoring, meetings, tasks, and reports |
